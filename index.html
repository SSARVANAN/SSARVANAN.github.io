How I work

From research question to measurable result

Each project starts from a real problem with limited labels or limited compute, uses a method that fits those limits, and ends with an evaluation others can check.

01 · Problem

Scarce labels, small budgets

Medical scans with few annotations, crop images from local farms, clinical questions that need a model small enough to run on modest hardware.

02 · Method

Fit the model to the data

Hybrid hand-crafted and learned features, unsupervised clustering, and parameter-efficient fine-tuning with LoRA and 4-bit quantization.

03 · Evidence

Evaluate and publish

Standard metrics such as BLEU, ROUGE-L, METEOR and F1, peer-reviewed venues, and open shared-task benchmarks.
